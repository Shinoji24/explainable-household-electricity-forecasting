# Explainable Household Electricity Consumption Forecasting and Anomaly Detection

## Project Overview
This project focuses on forecasting household electricity consumption and identifying unusual electricity usage patterns using machine learning techniques.

The aim is to understand historical electricity consumption, predict future usage, and detect unusual changes in consumption patterns.

## Objectives
- Analyse historical household electricity consumption data.
- Forecast future electricity consumption.
- Identify unusual consumption patterns using anomaly detection.
- Explain model predictions using explainable AI techniques.

## Dataset
**Source:** UCI Machine Learning Repository – Individual Household Electric Power Consumption.

The dataset contains household electricity measurements recorded at one-minute intervals.

## Technologies

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
